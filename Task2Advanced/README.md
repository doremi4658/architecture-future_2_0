# Task 2 — CI/CD + Remote Terraform State

Эта конфигурация автоматизирует развёртывание инфраструктуры Yandex Cloud с использованием GitHub Actions и удалённого состояния в Yandex Object Storage.

## Быстрый старт

### 1. Подготовка Yandex Object Storage

1. Создайте сервисный аккаунт с ролью `storage.editor` (или `admin`).
2. Сгенерируйте статические ключи доступа (Access Key и Secret Key).
3. Создайте бакет (например, `tfstate-backend`) с ограниченным доступом (приватный).

Опционально для блокировок:
- Создайте совместимую с DynamoDB таблицу в Yandex YDB и укажите её в `backend.tf`.

### 2. Настройка GitHub Secrets

Перейдите в репозиторий → **Settings** → **Secrets and variables** → **Actions** и добавьте:

| Секрет             | Описание                                      |
|--------------------|-----------------------------------------------|
| `YC_ACCESS_KEY`    | Статический ключ доступа Object Storage       |
| `YC_SECRET_KEY`    | Статический секретный ключ                    |
| `TF_BACKEND_BUCKET`| Имя бакета для tfstate (например, `tfstate-backend`) |
| `YC_CLOUD_ID`      | Идентификатор облака Yandex Cloud             |
| `YC_FOLDER_ID`     | Идентификатор каталога                        |
| `YC_TOKEN`         | IAM-токен для аутентификации провайдера (или используйте static keys) |

### 3. Использование

- **Pull Request**: при открытии PR в `main` автоматически выполняется `terraform plan` – результат виден в комментариях к PR (если настроить) или в логах Actions.
- **Ручной запуск**: перейдите на вкладку **Actions**, выберите workflow **Terraform CI/CD**, нажмите **Run workflow** и укажите `action`:
  - `plan` – просмотр изменений.
  - `apply` – применение изменений (требует подтверждения).

После `apply` инфраструктура будет создана, а состояние сохранено в Object Storage.

## Как убедиться, что состояние не локальное

- В репозитории нет файлов `*.tfstate` (они в `.gitignore`).
- При повторном запуске `init` Terraform подключается к удалённому бэкенду и загружает актуальное состояние.

## Расширение для разных окружений

Скопируйте workflow и измените переменную `TF_BACKEND_KEY` на `stage/terraform.tfstate`, `prod/...` или используйте матрицу окружений.

## Требования

- Terraform >= 1.3
- GitHub репозиторий с настроенными секретами
- Доступ к Yandex Cloud
- Сервисный аккаунт с правами на Object Storage и управление облачными ресурсами
