# Task5Advanced — Технологический ландшафт и стоимостной анализ

## 1. Расширенный технический радар (`tech-radar.md`)

Технический радар сгруппирован по категориям: **архитектурные паттерны**, **облачная инфраструктура**, **интеграция и данные**, **аналитика и BI**, **DevSecOps**.  
Каждой технологии или паттерну присвоен статус:

- **Adopt** – использовать в первую очередь,  
- **Trial** – активно пилотировать,  
- **Assess** – исследовать на предмет ценности,  
- **Hold** – не использовать, выводить из эксплуатации.

### Квадрант: Архитектурные паттерны

| Технология / Паттерн | Статус | Обоснование |
|----------------------|--------|-------------|
| Data Mesh | **Adopt** | Ключевой подход для независимости доменов и масштабирования аналитики |
| Event-Driven Architecture (EDA) | **Adopt** | Основа целевой событийной платформы, асинхронная интеграция |
| Domain-Driven Design (DDD) | **Adopt** | Базовый метод выделения Bounded Contexts и агрегатов |
| Self-Service BI (data product thinking) | **Adopt** | Портал самообслуживания — главная витрина для бизнес-пользователей |
| Microservices (per domain) | **Adopt** | Каждый домен как независимый сервис |
| Monolithic DWH (централизованное) | **Hold** | Текущий DWH SQL Server — legacy, подлежит замене |
| Centralized ESB (Camel) | **Hold** | Используется только как временный мост |
